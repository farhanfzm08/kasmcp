# Kas MCP - Sistem Kas Sosial Measuring Center

Aplikasi Manajemen Kas Sosial dan Santunan Anggota berbasis Next.js 16, Prisma ORM 7, dan Supabase PostgreSQL.

## Fitur Utama
- Dashboard Keuangan Realtime & Statistik Kas
- Manajemen Anggota & Verifikasi Pembayaran (Single & Multi-pay)
- Pengelolaan Santunan (Keluarga & Anggota Inti)
- Pengingat Tagihan Massal WhatsApp (Fonnte API)
- Laporan Keuangan & Audit Log

## Deployment
Deployed on Vercel with Supabase Database.
